# Kanth Basavaraju

Product leader building agentic AI for enterprise workflows. Everything here is
personal and open source: tools for deciding where AI belongs in a business
process, and for keeping AI agents inside policy when they act on systems of record.

## Projects

- **[agentic-policy-guardrails](https://github.com/skkanthb/agentic-policy-guardrails)**:
  a policy-as-code control plane (OPA/Rego) that checks AI agent tool calls before
  they write to systems of record, tested end to end with an Azure AI Foundry agent
  against a live SAP S/4HANA sandbox.
- **[AI Solution Fit Advisor](https://skkanthb.github.io/ai-solution-fit-advisor)**:
  tells enterprise teams whether each process step needs rules, a system feature,
  ML, an LLM or an agent.
- **[civic-policy-engine](https://github.com/skkanthb/civic-policy-engine)**:
  a statutory rules engine in OPA/Rego, modeled on a public housing grant, showing
  policy kept separate from application code.
- **Conversational ERP prototype (2020)**: built before LLMs were widely available.
  [Demo](https://youtube.com/watch?v=f4cdx9-7EHo)
